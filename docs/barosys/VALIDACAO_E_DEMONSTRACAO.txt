ROTEIRO DE DEMONSTRAÇÃO (SEM DADOS REAIS)
1. npm run dev -- --host 127.0.0.1 --port 1431.
2. Abrir /scripts/barosys-preview.html; banner indica fixture isolada.
3. Condições e qualidade -> conferir denominadores/limites/versão.
4. Quadros e regiões -> Carregar série -> Média/Máximos/Quadro; tempo/pausa.
5. Selecionar células/retângulo; salvar revisão; conferir parcela não atribuída.
6. Vista 3D -> rotação/zoom por teclado -> Voltar ao 2D.
7. Oscilação -> trecho, evento, quadro selecionado -> Mostrar quadro no mapa.
8. ?page=report -> carregar prévia -> selecionar seções -> exportar PDF.
9. ?page=comparison -> escolher 2 e 4 -> métodos/condições/máscaras/deltas.
10. ?volume=10000 -> carregar série -> último quadro / reprodução / pausa.
O entrypoint de produção não importa a fixture; não existe rota extra no app.
