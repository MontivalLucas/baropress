# Anamnese para avaliação baropodométrica — BAROPRESS

Versão 1 • 07/10/2026 • 40 perguntas

Entrevista inicial sobre sintomas, saúde dos pés, antecedentes e mobilidade. Modelo autoral para revisão pelo responsável clínico; não é escala validada nem gera diagnóstico ou liberação automática do exame. Dados cadastrais permanecem no prontuário. Perguntas 'Se sim' podem ficar em branco quando não se aplicarem.

## Aplicação

Vincular ao paciente cadastrado; nome, nascimento, profissão, peso, altura e número do calçado já existem no prontuário. Registrar respostas como relato do paciente e reservar o último grupo ao profissional. A data é registrada pelo sistema ao salvar. O modelo deve ser revisado pelo responsável clínico antes do uso assistencial.

## Orientações para implementação

- O JSON usa o formato `Questionnaire` existente, com IDs nulos para criação de um novo modelo. Ele é um recurso para integração, não um backup importável.
- Desde a versão 0.2.7, o JSON é incluído no executável e registrado automaticamente na primeira abertura de Questionários após login. O registro ocorre uma vez por banco e preserva edições/inativação posteriores. Um modelo existente com o mesmo nome é adotado sem sobrescrever seu conteúdo.
- O módulo permite Responder e Editar pelo fluxo existente; não há importador genérico de arquivos de modelo. O JSON permanece como fonte do modelo distribuído.
- Manter campos condicionais opcionais: o módulo atual não possui exibição condicional. Não preencher respostas automaticamente.
- Campos de seleção múltipla podem ficar vazios; vazio significa não respondido, não ausência de doença ou limitação. Evitar opções incompatíveis como 'Nenhuma' junto de diagnósticos.
- Não calcular pontuação clínica ou diagnóstico com essas respostas. 'Não sei informar' e decisão pendente exigem revisão humana.
- Feridas, alterações recentes nos pés, redução de sensibilidade, quedas e incapacidade de permanecer em pé devem ser revisadas pelo profissional antes de decidir sobre a coleta; o questionário não estabelece contraindicações universais.
- Guardar cada aplicação no histórico usando a cópia do modelo já suportada pelo programa. Restringir o acesso aos dados de saúde à equipe autorizada.

## Fundamentação dos temas

Este é um roteiro autoral, não uma reprodução nem uma escala validada. Os temas sobre sensibilidade e lesões foram orientados pelo [NIDDK — Diabetes & Foot Problems](https://www.niddk.nih.gov/health-information/diabetes/overview/preventing-problems/foot-problems). Os temas sobre quedas, marcha, equilíbrio e calçados foram orientados pela [NICE NG249 — recomendações](https://www.nice.org.uk/guidance/ng249/chapter/Recommendations), cujo escopo é pessoas idosas e pessoas a partir de 50 anos com maior risco; não extrapolar classificações de risco para toda a população.
