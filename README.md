# Backup local do TCC — 2026-11-06

Snapshot exato dos arquivos locais antes da limpeza autorizada.

Baixe `arquivos-tcc.zip` e extraia para restaurar as quatro pastas originais. `manifesto.json` registra o tamanho e SHA-256 de cada arquivo.

Os diretórios `.git`, `node_modules` e `.private` foram excluídos do arquivo e preservados localmente. O código principal também permanece no histórico da branch `main`.

Este backup mantém versões antigas, documentos, imagens, fontes, composições, renders, saídas compiladas e relatórios. Nenhuma composição foi modificada.
